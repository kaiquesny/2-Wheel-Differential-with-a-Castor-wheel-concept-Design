# 2-Wheel-Differential-with-a-Castor-wheel-concept-Design
Este é um projeto simples de um robô móvel diferencial de 2 rodas com uma roda louca (castor wheel). Fiz a modelagem 3D inicial no PTC Creo, depois exportei o arquivo para o SolidWorks para conseguir rodar uma simulação física no Simscape. A ideia é usar essa base para testar o comportamento de diferentes plataformas de robôs móveis.
